### 波函数

单色平面波$\psi(x,t) = \psi_0e^{-i(\omega t-kx)} = \psi_0e^{-\frac{i}{\hbar}(Et-px)}, \omega = \frac{E}{\hbar}, k = \frac{p}{\hbar}$。k叫做波矢。两种形式对应波函数的时间域表示和能量域表示。

三维的波函数为$\psi(\mathbf r,t) = \psi_0e^{-\frac{i}{\hbar}(Et-\mathbf p\cdot \mathbf r)}$

波函数的物理意义为，$|\Psi|^2$必须是几率密度，即$\rho(\mathbf r,t)=|\psi(\mathbf r,t)|^2=\psi(\mathbf r,t)^*\psi(\mathbf r,t)$

$\rho(\mathbf r,t)dV$是在粒子出现在体积元的概率，对多粒子系统，乘以总粒子数就是粒子数期望

所谓的归一化条件就是概率为1，即$\int_\Omega\psi^*(\mathbf r,t)\psi(\mathbf r,t)dV = 1$

注意常用积分$\int_{-\infty}^{+\infty}e^{-ax^2}dx = \sqrt{\frac{\pi}{a}}$

## 力学量与算符

一切规律体现在作用与的函数，相等相加相乘等。乘法交换即对易关系，不可随意交换。

### 对易关系

如对易，则$\hat A \hat B \psi = \hat B \hat A \psi$。记为$[\hat A, \hat B] = \hat A \hat B - \hat Bv\hat A = 0$

常见关系：

$[\hat A, \hat B] = -[\hat B, \hat A]$

$[\hat A, \hat B + \hat C] = [\hat A, \hat B] + [\hat A, \hat C]$

$[\hat A, \hat B \hat C] = \hat B[\hat A, \hat C] + [\hat A, \hat B]\hat C$

$[\hat A \hat B, \hat C] = \hat A[\hat B, \hat C] + [\hat A, \hat C]\hat B$

这是作业题，直接展开即可证明

线性性（位置、动量）与非线性（根号）

### 常见算符

动量算符 $\hat p_x = -i\hbar\frac{\part}{\part x}, \hat p^2 = -\hbar^2\nabla^2$

动量对易：$[\hat z, \hat{p_x}] = 0, [\hat y, \hat{p_z}] = 0, [\hat x, \hat{p_y}] = 0，[\hat p_x, \hat{p_y}] = 0, [\hat p_x, \hat{p_z}] = 0, [\hat p_y, \hat{p_z}] = 0$

$[\hat x, \hat{p_x}] = i\hbar, [\hat y, \hat{p_y}] = i\hbar, [\hat z, \hat{p_z}] = i\hbar$

动能算符 $E = -\frac{\hbar^2}{2m}\frac{\part^2}{\part x^2}, \hat E = -\frac{\hbar^2}{2m}\nabla^2, E = \frac{P^2}{2m}$

哈密顿算符 $H = -\frac{\hbar^2}{2m}\frac{\part^2}{\part x^2}+U(x,t), \hat H = -\frac{\hbar^2}{2m}\nabla^2+U(\mathbf r,t)$

角动量算符 $\hat{\mathbf L} = \mathbf r \times \hat{\mathbf p}$

$\hat L_x = y\hat p_z - z \hat p_y$

$\hat L_y = z\hat p_x - x \hat p_z$

$\hat L_z = x\hat p_y - y \hat p_x$

角动量算符的互易关系有：

$[\hat L_x, \hat L_y] = i\hbar \hat L_z$

$[\hat L_y, \hat L_z] = i\hbar \hat L_x$

$[\hat L_z, \hat L_x] = i\hbar \hat L_y$

而$\hat L^2$与其分量对易，$[\hat L^2, \hat L_x] = [\hat L^2, \hat L_y] = [\hat L^2, \hat L_z] = 0$

注意直角坐标系与球坐标的变换：
		$x = r\sin\theta\cos\phi\qquad r^2 = x^2+y^2+z^2$

$y = r\sin\theta\sin\phi\qquad \cos\theta = z/x$

$z = r\cos\theta\qquad\qquad~ \tan\theta = y/x$

### 势阱

经典例题即无限深方势阱。我们要求的方程形式为：

$(-\frac{\hbar^2}{2m}\frac{\part^2}{\part x^2}+U(x))\psi(x) = E\psi(x)$

题目一般给出$U(x)$，可知$U(x) = \infty$处$\psi = 0$，再根据其他位置写出方程，加上波函数连续的边界条件，就解出波函数和能量

当$U(x) = 0, 0\leq x \leq a$，结论为$E = \frac{\hbar^2n^2\pi^2}{2ma^2}, \psi_0 = \sqrt{\frac{2}{a}}\sin\frac{n\pi}{a}x$
